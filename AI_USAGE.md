# AI Usage Declaration

## Project: Consultation Recording Manager

This document declares all AI tools used during the development of this project, as required by the Humara Pandit Engineering Hiring Challenge.

## AI Tools Used

### 1. Claude (Anthropic) — Primary Development Assistant
- **Model**: Claude Sonnet 4.6
- **Usage**:
  - Scaffolding the MERN project structure
  - Generating boilerplate code for Express routes, Mongoose models, and React components
  - Writing JWT authentication middleware
  - Setting up Multer for file/audio upload handling
  - Debugging async/await patterns in React hooks
  - Reviewing and suggesting improvements to API error handling

### 2. GitHub Copilot — In-Editor Autocomplete
- **Usage**:
  - Inline code suggestions while typing
  - Completing repetitive patterns (e.g., CRUD route handlers, form field mappings)
